# CLAUDE.md — cfbfastR

`cfbfastR` is the R package for clean, tidy college-football
play-by-play, schedule, roster, ratings, betting, recruiting, and
box-score data. It wraps **CollegeFootballData (CFBD)**, **ESPN**
college-football endpoints, plus **Fox Sports** and **Yahoo**.
Companions: `sportsdataverse`/`cfbfastR-py` (Python CFB surface), and
the `cfbfastR-cfb-raw` (scraper) + `cfbfastR-cfb-data`
(modeling/release) pipeline repos. Released on CRAN + r-universe. Docs:
<https://cfbfastR.sportsdataverse.org>.

- **Version:** 3.0.0 (DESCRIPTION) · **License:** MIT · **R:** \>= 4.1.0
  (native pipe `|>`)
- **Branch:** `main` is default + release branch.
- **Maintainer:** Saiem Gilani.

When this guide differs from the repo, treat `CONTRIBUTING.md` and the
current `tests/testthat/` suite as authoritative.

## Architecture (data sources + function families)

Five source-prefixed families; `R/` is grouped by prefix:

| Prefix | Source | Auth | Notes |
|----|----|----|----|
| `cfbd_*` | collegefootballdata.com | **`CFBD_API_KEY` bearer token** | games/plays/drives/teams/players/stats/ratings/recruiting/draft/betting/venues/coaches/conferences/metrics |
| `espn_cfb_*` / `espn_metrics_*` / `espn_ratings_*` | ESPN (`site.api.espn.com` + `sports.core.api.espn.com`) | none | ~75 wrappers (3.0.0 expanded ESPN from 8 → 73); core-v2 `$ref`-heavy payloads |
| `fox_cfb_*` | `api.foxsports.com/bifrost/v1/cfb` | public web key | 8 wrappers (pbp/boxscore/odds/roster/stats/gamelog/standings/leaders); key overridable via `options(cfbfastR.fox_key=)` |
| `yahoo_cfb_*` | Yahoo Sports | none | scoreboard/boxscore/player+team season stats |
| `load_cfb_*` / `load_espn_cfb_*` / `load_ncaa_mfb_*` | release artifacts | none | 43 full-season loaders from `sportsdataverse-data` releases |

**CFBD API key:**
[`register_cfbd()`](https://cfbfastR.sportsdataverse.org/reference/register_cfbd.md)
saves `CFBD_API_KEY`;
[`cfbd_key()`](https://cfbfastR.sportsdataverse.org/reference/register_cfbd.md)
/
[`has_cfbd_key()`](https://cfbfastR.sportsdataverse.org/reference/register_cfbd.md)
/
[`cfbd_api_key_info()`](https://cfbfastR.sportsdataverse.org/reference/register_cfbd.md)
inspect it. Register at <https://collegefootballdata.com/key>.

**Loaders:** `load_cfb_pbp(seasons)` pulls per-season `.rds` from the
`sportsdataverse-data` release tag `cfbfastR_cfb_pbp` (**floor 2014**,
default `most_recent_cfb_season()`); `load_cfb.R` has
`load_cfb_rosters/_schedules/_teams`.
[`update_cfb_db()`](https://cfbfastR.sportsdataverse.org/reference/update_cfb_db.md)
builds/refreshes a local SQLite copy. Progress via `progressr` (optional
Suggest) — there is no `furrr`/`future` parallelism.

**Release-dataset loaders (3.0.0):** three
generated-then-hand-maintained files follow the wehoop `load_ncaa_wbb.R`
shape (seasons vector or `TRUE`, progressr, `rbindlist`,
`dbConnection`/`tablename` write-through with dots forwarded to
`dbWriteTable`): `R/load_espn_cfb.R` (27 `load_espn_cfb_*` ESPN-derived
datasets, mostly 2004+), `R/load_cfb_datasets.R` (11 ratings / talent /
recruiting / crosswalk datasets), `R/load_ncaa_mfb.R` (10 stats.ncaa.org
datasets, 2013+, incl. FCS). One loader per release tag; stem == asset
file prefix. Parquet-only tags go through
[`parquet_from_url()`](https://cfbfastR.sportsdataverse.org/reference/parquet_from_url.md)
(`utils.R`, arrow is Suggests → guarded by
[`rlang::check_installed`](https://rlang.r-lib.org/reference/is_installed.html)).
PBP delineation: `load_cfb_pbp` = classic cfbfastR EPA pbp (2014+);
`load_espn_cfb_pbp` = ESPN-derived 469-col pbp (2004+);
`load_ncaa_mfb_pbp` = native stats.ncaa.org parse;
`load_ncaa_mfb_pbp_cfbfastr` = same plays on cfbfastR column
conventions. When a new tag appears on sportsdataverse-data, add a
loader to the matching file following the neighboring function’s shape.

**Modular PBP/EPA/WPA engine** (`R/pbp_*.R`, landed in 3.0.0): legacy
entry points
[`cfbd_pbp_data()`](https://cfbfastR.sportsdataverse.org/reference/cfbd_pbp_data.md) +
`espn_cfb_pbp(epa_wpa=)` and **v2** orchestrators
[`cfbd_pbp_data_v2()`](https://cfbfastR.sportsdataverse.org/reference/cfbd_pbp_data_v2.md) +
[`espn_cfb_pbp_v2()`](https://cfbfastR.sportsdataverse.org/reference/espn_cfb_pbp_v2.md)
both feed one shared `.run_epa_wpa()` engine (`pbp_epa_wpa_engine.R`).
Flow: `.cfbd_to_epa_input()` / `.espn_to_epa_input()` adapters
(`pbp_adapters.R`) → engine → play taxonomy centralized in
`pbp_taxonomy.R` (single source of truth, replaced 4 drifted copies) →
`.pbp_apply_output_schema(df, output=)` applies `.pbp_output_order`
column order + the **`"default"`/`"lean"`/`"full"` tier** selectors
(`pbp_output_schema.R`). Models are mgcv/nnet/xgboost EP/FG/WP. ESPN
team/venue/coach metadata the bare payload omits is resolved by
`.espn_pbp_game_meta()`.

## Conventions

- **Native pipe `|>` only** — `%>%`/`magrittr` swept out; not in
  Imports. `|>` rejects `[[` as RHS (use
  [`purrr::pluck()`](https://purrr.tidyverse.org/reference/pluck.html))
  and has no `.` placeholder (use `_` or `\(x)`).
- **Initialize every `tryCatch` return variable BEFORE the block**
  (e.g. `plays_df <- data.frame()`). On API error the handler runs, the
  var never binds, and `return(var)` throws `object not found` instead
  of the intended `cli_alert_danger()` + empty fallback. Applies to all
  return names; init
  [`list()`](https://rdrr.io/r/base/list.html)/`NULL`/[`data.frame()`](https://rdrr.io/r/base/data.frame.html)
  as appropriate.
- **Scalar-default args, not `c(...)` +
  [`match.arg()`](https://rdrr.io/r/base/match.arg.html).** Default
  `output = "default"`, document choices in `@param`, validate with
  [`cli::cli_abort()`](https://cli.r-lib.org/reference/cli_abort.html).
  The c-vector form silently picks the first element on a vector arg.
- **`cli` for all messaging:** `cli_alert_danger/warning/info/success`
  inside handlers; `cli_abort/cli_warn` for raised conditions. Pass
  `{conditionMessage(e)}`, never raw `{e}` (glue coerces the condition).
- **Pipeline tail:**
  `... |> janitor::clean_names() |> make_cfbfastR_data("<desc>", Sys.time())`
  sets class
  `c("cfbfastR_data","tbl_df","tbl","data.table","data.frame")` +
  timestamp/type attrs. Apply it **after** the final dplyr verb (dplyr
  strips the class).
- **Column-drift resilience:** drop with
  `dplyr::select(-dplyr::any_of("col"))`, rename with
  `rename(any_of(c(new = "old")))` — both APIs add/rename columns over
  time.
- **Null safety:** `%||%` (re-exported from rlang via `@importFrom`;
  don’t redefine).
- **ESPN self-describing returns:** catalog wrappers call
  `.attach_query_meta_auto()` (`utils_attach_query_meta.R`), which
  introspects caller formals and lifts query args
  (`season`/`week`/`team_id`/…) onto the frame as leading columns
  (`year`→`season`); add a conventionally-named arg and it auto-flows.
  Response columns win on name collision.
- **Proxy:** `get_req()` resolves `proxy=` arg →
  `getOption("cfbfastR.proxy")` → `http(s)_proxy` env. Thread
  `proxy = NULL`/`...` through new wrappers for per-call override.

## Caching

ESPN catalog calls are memoised (`cachem` + `memoise`, wired in `zzz.R`
`.onLoad`): `options(cfbfastR.cache = "memory"|"filesystem"|"off")`
(default `memory`), `options(cfbfastR.cache_duration = 86400)` (TTL
seconds).
[`espn_cfb_clear_cache()`](https://cfbfastR.sportsdataverse.org/reference/espn_cfb_clear_cache.md)
forgets all cached endpoints; filesystem backend persists under
`tools::R_user_dir("cfbfastR","cache")`. **CFBD endpoints are NOT
cached** (pagination/date variation would return wrong rows).

## Testing

- Tests gate network calls with `skip_on_cran()` + `skip_on_ci()` (and a
  few `skip_if()`). `setup-cfbd-throttle.R` hot-swaps `get_req()` to
  [`Sys.sleep()`](https://rdrr.io/r/base/Sys.sleep.html) between CFBD
  calls (avoids 429 storms); tune with
  `options(cfbfastR.test_request_delay=)`. `Config/testthat/edition: 3`.
- **Column assertions use the subset direction:**
  `expect_in(sort(expected), sort(colnames(x)))` (expected ⊆ actual) so
  a new upstream column doesn’t fail the run. Add a skip-if-empty guard
  right after every API call (`if (nrow(x)==0) skip(...)`) for transient
  500s/429s.
- **`test-pbp_equivalence.R`** asserts v2 reproduces legacy
  [`cfbd_pbp_data()`](https://cfbfastR.sportsdataverse.org/reference/cfbd_pbp_data.md)/[`espn_cfb_pbp()`](https://cfbfastR.sportsdataverse.org/reference/espn_cfb_pbp.md)
  column-for-column, with an explicit allow-list of intentional deltas
  (character `id_play`, logical `scoring_play`, total-seconds
  `clock_seconds`, short-name `*_player_name`). Any other diff is a
  regression. Tier-monotonicity tests verify `lean ⊆ default ⊆ full`.

## Gotchas

- **`refactor/pbp-epa-wpa-modular` is merged** — the modular engine +
  ESPN catalog expansion shipped in 3.0.0 on `main`. Don’t look for a
  separate dev branch.
- **CFBD rate limits:** free tier caps per-minute; wrappers surface
  `cli_alert_danger` on 429 but don’t hot-retry —
  [`Sys.sleep()`](https://rdrr.io/r/base/Sys.sleep.html) and re-run the
  range.
- **ESPN `$ref` payloads:** core API returns `{"$ref": "..."}`
  placeholders instead of inlined team/athlete/venue records. Route
  team-metadata consumers through `.espn_pbp_game_meta()` (falls back to
  cached `.espn_cfb_team_lookup()`), not raw field reads.
- **`season` convention:** calendar year of the fall season (Jan-2024
  Rose Bowl is `season=2023`); OT possessions model as drives with
  `period >= 5`.
- Functions deprecated via
  [`lifecycle::deprecate_stop()`](https://lifecycle.r-lib.org/reference/deprecate_soft.html) +
  `@keywords internal` live in `cfbd_metrics.R` / `espn_cfb_ratings.R`
  and are excluded from the pkgdown index.
- **`_pkgdown.yml`** auto-picks
  `starts_with("cfbd_"/"espn_cfb_"/"load_cfb_")`; other new exports need
  a manual `reference:` entry. Keep `NEWS.md` / `cran-comments.md` /
  `_pkgdown.yml` in sync on any API-surface change. New `NEWS.md`
  bullets go under the current `# **cfbfastR v3.0.0**` heading — don’t
  open a new version section before release.
- Never hand-edit `NAMESPACE` or `man/` — regenerate with
  `devtools::document()`.
- **Never add AI co-author trailers (Claude/Copilot/etc.) to commits.**
  Conventional Commits
  (`feat:`/`fix:`/`docs:`/`test:`/`refactor:`/`chore:`/`ci:`), scope
  when useful (`fix(pbp): ...`). \`\`\`
